# Reference pages

Static, hand-built pages that define the look before components exist (D-74, D-76). Components built in P2–P4 must reproduce them.

| Page | Status | Files |
| --- | --- | --- |
| Registry activation (form, serial error, code created, limit reached) | v2 — warm palette, light + dark; awaiting owner approval | `registry-activation/`, `shots/` |

Open `registry-activation/index.html` directly in a browser. Query parameters: `?state=form|error|success|limit&theme=light|dark`. The small black bar at the bottom is a review tool, not part of the design.

`tokens.css` here is a generated preview of the P1 Style Dictionary output. `nds.css` is temporary: its rules move into component CSS Modules in P2–P4.
