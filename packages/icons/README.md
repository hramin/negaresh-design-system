# @negaresh/icons

SVG icon set on a 24 grid, stroke from token, `currentColor`. Exposes React components; directional icons carry `mirrored`. Licence of the source set recorded in LICENSE.

Status: 76 icons (P2). `import { iconCopy } from '@negaresh/icons'`, render with `<Icon icon={iconCopy} />` from `@negaresh/react`. Regenerate with `pnpm --filter @negaresh/icons import`. Licence: `LICENSE` (NDS glyphs + Lucide ISC).
