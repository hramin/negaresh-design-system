### Deviations and notes

- `@negaresh/tokens` emits `dist/tokens.js` + `dist/tokens.d.ts` (not a `tokens.ts` source) plus `dist/contrast.json` for the colour page. `03-architecture.md` lists `tokens.ts`.
- Contrast pairs: ported all pairs from the report and added four (`fg.default` and `fg.muted` on `bg.surface`, `fg.inverse` on `bg.inverse`, `focus.ring` on `bg.surface`). All 56 pass. The gate compares at the reported two-decimal precision.
- DTCG validation is our own validator (`packages/tokens/src/validate.ts`): structure, types, value shapes, alias resolution and type match, colour `hex` vs components, light/dark name parity. No network fetch of the schema (on-prem friendly).
- The docs site cannot be built from NDS components yet (none exist). Temporary local pieces (ThemeProvider stub, theme switch on native radios, CopyButton, StatusBadge, TableWrap) are replaced by `@negaresh/react` in P2–P4. Chrome strings live in `apps/docs/src/lib/messages.ts` until Paraglide is added.
- The theme switch works only after hydration (it writes a cookie). Without JavaScript the page still follows the OS or the cookie; `?theme=` works everywhere. A no-JS fallback (form submit) can come with the real ThemeSwitch in P2.
- Mobile (below 900 px) shows card lists instead of the token and colour tables.
- Media queries use the literal `900px` (custom properties cannot be read in media queries); the value is `--nds-breakpoint-md`.
- stylelint also bans physical sizing (`width`, `height`, `min-/max-*`): use `inline-size`/`block-size`.
- Biome does not format Markdown or `tokens/` (avoids rewriting the P0 documents).
- Vazirmatn subset: 72 KB woff2 with the full 100–900 weight axis (budget 90 KB).
- Playwright: visual snapshots are not a gate yet (needs the fixed Docker image with fonts, `quality.md`); `SCREENSHOTS=1 pnpm test:e2e` captures review screenshots. Locally, `PW_CHROMIUM_PATH` can point at a preinstalled Chromium.
- No favicon until the logos exist (Q-02); the site declares an empty icon to avoid a 404 per page.
