## Scope

- `@negaresh/charts`: IntervalBar, ProfileLine, Bar, Radar, Gauge, Sparkline, ChartFrame — SSR SVG, table alternative (plus `ReferenceLine` and `Band` primitives per `docs/components.md`).
- `@negaresh/assessment`: QuestionItem, AnswerPage, AnswerProgress, StartForm, ResumeOrRestart, ResultSummary, ScoreTable, InterpretationBlock (pro/calm), ResultChart, ReportStatus, PrintLayout (A4), SubmittedPage.
- Fixtures: MMPI-Teen-13 and Wellbeing-8 result shapes from the test platform API (`/api/v1`).
- Print pipeline demo: render result → Playwright PDF in CI; compare to screen snapshot.
